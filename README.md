# ❓ Quiz Simples

Aplicação de quiz interativo com perguntas e alternativas, desenvolvida com HTML5, CSS3 e JavaScript puro.

## ✨ Funcionalidades

- Perguntas com múltipla escolha
- Feedback imediato de acerto/erro
- Contagem de pontuação
- Interface interativa e responsiva

## 🛠️ Tecnologias Utilizadas

- HTML5
- CSS3
- JavaScript (ES6+)

## 📁 Estrutura do Projeto

```
Projeto8-Quiz-Simples/
├── index.html
├── css/
│   └── style.css
└── js/
    └── script.js
```
